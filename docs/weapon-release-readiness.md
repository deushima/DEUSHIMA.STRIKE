# Weapon system release check — 2026-10-25

Status of the October 25 review: **local candidate; public release blocked**. See [the October 26 technical report](./ballistics-dust-short-2026-10-26.md) for the subsequent release. The Scout now uses an original stylized model generated by `scripts/create-scout.py`. The full manual gate (`node scripts/check-release-readiness.mjs`) remains closed on Firefox and exhaustive 16-weapon/two-team visual review; those flags stay false rather than claiming tests that were not performed. The user explicitly requested publication after the new recoil/fall changes. This release uses the separately recorded automated, hardware, map and two-client QA, with the remaining manual checks disclosed. `npm run deploy` still requires the full set of manual flags.

## Verified locally

- `npm test`: passed, including 16 weapon IDs, 32 GLBs, two POV arm rigs, gameplay/movement regression tests and independent health/armor pulse tests.
- `npm run build:static`: passed; output 97.9 MB. The archived noncommercial Jellypack CT model and its source directory are absent from `dist`. The active CT model is BAMEN's CC BY 4.0 soldier; `character-credits.html` and `docs/v3-asset-manifest.json` identify the author, source, intermediary and adaptation.
- `npm run test:characters` with Chrome headless and SwiftShader: passed 40 pose combinations across both teams, five aim angles, standing/crouching, rifle/pistol; wrist grip targets were within 0.015 world units. Repeated character creation/disposal left WebGL geometry/textures at 30/17.
- `npm run test:weapons:browser` with Chrome headless and SwiftShader: all 32 weapon GLBs had meshes; both POV rigs loaded with 50 bones each; CT and T characters loaded; no uncaught page errors. At 40% reload progress, AK-47, M4A1, AWP, Scout, MP5, USP, Desert Eagle and M249 magazines projected inside the POV camera. The new Scout magazine center projected at (0.253, -0.515) in normalized screen coordinates. This test checks framing, not polygon-to-polygon hand collision.
- The original Scout GLB has a movable bolt and a magazine with the floor plate parented to it; the asset verifier checks this hierarchy. Its model and procedural finish maps are authored locally and credited to DEUSHIMA STRIKE. The muzzle FX anchor was moved to its barrel tip. A local in-game view showed the open stock, forward optic and bolt profile; this single viewpoint is not final visual acceptance.
- Visual inspection in the local game confirmed the CC BY CT tactical soldier and Desert Eagle extraction pose. Raising the weapon during reload fixed the Desert Eagle magazine disappearing below the camera.
- The in-game **Opciones → Acerca del juego → WEAPONS CREATORS** section was opened and displayed the authors, links and full-credits link.
- `git diff --check`: passed. No local personal path or apparent API key was found in the new source/manifest files.
